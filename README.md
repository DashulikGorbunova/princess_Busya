# Принцесса Буся

Закрытый фотодневник на двоих. Пароль для просмотра открывает ленту, а пароль для загрузки также позволяет добавлять фотографии с датой и подписью.

Без зависимостей. Собрать Worker командой `npm run build`. Точка входа после сборки находится в `dist/server/index.js`.

Хостинг передаёт Worker привязку R2 `BUCKET` и секреты `READER_PASSWORD`, `WRITER_PASSWORD`, `SESSION_KEY`. Для каждой роли нужен отдельный случайный пароль, а для подписи сессий — отдельный случайный ключ. Обложка сгенерирована.
